# Project Guidelines

Local OSS Helper rules for RHAF Portal Operator.

- Fix branch naming pattern: `ci-issue-<ISSUE_NUMBER>`
- Feature branch naming pattern: `feature/<ISSUE_NUMBER>-<short-slug>`
- Bugfix branch naming pattern: `bugfix/<ISSUE_NUMBER>`
- Quick-fix branch naming pattern: `quick-fix/<short-slug>`
- SonarCloud branch naming pattern: `ci-issue-<ISSUE_NUMBER>`
- Commit format (fix): `Fix #<ISSUE_NUMBER>: <brief description>`
- Commit format (quick-fix): `chore: <brief description>`
- CI-fix branch naming pattern: `ci-issue-<ISSUE_NUMBER>`
- Commit format (ci-fix): `ci: <brief description>`
- PR creation policy: always
- Find-task source: GitHub labels
- Find-task beginner label: `good first issue`
- Find-task intermediate label: `help wanted`
- Find-task experienced label: `help wanted`
- Scope-too-large redirect: Request maintainer direction.
